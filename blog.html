本文记录实验一的制作与发布过程：页面文件、用到的标签、Git 与 GitHub Pages 的部署命令、HTTP 协议版本的检查结果。

1. 页面文件

my-web-home/
├── index.html      学校介绍（首页）
├── campus.html     校园风光
├── blog.html       本页
└── css/
    └── style.css   三个页面共用的样式表
表 1 页面中使用的 HTML 标签
标签用途
<h1> <h2>页面标题与小节标题
<p> <ul> <li>段落与列表
<a href>页面互链与指向校外网站的链接
<img src alt>校园照片
<table> <caption> <th> <td>学校概况、历史节点、院系方向等表格
<div class="note">提示块
<figure> <figcaption>图片与图下说明
<header> <nav> <footer>页头、导航条、页脚
<pre> <code>本页的命令与目录结构

样式表 143 行，写在一个文件里：body 限制宽度并居中，h2 加左侧竖线，表格加边框与隔行底色，最后一段 @media (max-width: 600px) 处理手机宽度。

2. 提交与部署

git init -b main
git add .
git commit -m "add lab 1 webpage"
git remote add origin https://github.com/A1exthegreat/my-web-home.git
git push -u origin main

再指定 Pages 用 main 分支的根目录发布：

gh api -X POST repos/A1exthegreat/my-web-home/pages \
    -f "source[branch]=main" -f "source[path]=/"

3. HTTP 协议版本检查

打开已发布的页面，按 F12 打开开发者工具，切到 Network 面板，刷新页面，在表头勾出 Protocol 列。主文档与样式表、图片都显示 h2，即 HTTP/2。

命令行复查，结果一致：

$ curl -sS -o /dev/null -w "%{http_version}\n" \
    https://a1exthegreat.github.io/my-web-home/
2

$ curl -v -I https://a1exthegreat.github.io/my-web-home/ 2>&1 | grep -E "ALPN|using|HTTP/2"
* ALPN: curl offers h2,http/1.1
* ALPN: server accepted h2
* using HTTP/2
< HTTP/2 200
